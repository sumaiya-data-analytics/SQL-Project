# Retail Store SQL Analysis

# Project Overview
This project focuses on designing and analyzing a Retail Store database using SQL. It includes practical SQL queries to retrieve, filter, manipulate, and analyze retail business data.

# Project Objectives
- Design a normalized relational database schema.
- Work with customers, products, orders, order items, payments, and product reviews.
- Solve real-world business questions using SQL queries.
- Perform data analysis using different SQL concepts.

# Tools & Technologies
- MySQL
- MySQL Workbench

# SQL Concepts Covered

1. SQL Basics: SELECT, DISTINCT, WHERE, ORDER BY.
2. Filtering and Formatting: AND, IN, BETWEEN, LIKE, IS NULL, Aliases, CONCAT.
3. Aggregate Functions:COUNT, SUM, AVG, ROUND.
4. Grouping:GROUP BY.
5. Joins:INNER JOIN, LEFT JOIN, RIGHT JOIN.
6. Subqueries:Nested Queries and Correlated Subqueries.
7. Set Operations:UNION and related queries.

# Database Tables
- Customers
- Products
- Orders
- Order Items
- Payments
- Product Reviews

# Business Analysis
- Retrieve customer and product information.
- Calculate total revenue and average order value.
- Analyze customer-wise sales.
- Identify popular product categories.
- Analyze orders and payment methods.
- Identify customers who have not placed orders.
- Find products that have never been ordered.
- Identify highest-value orders per customer.

# Key Learnings
- Writing SQL queries for business requirements.
- Understanding relational databases.
- Working with multiple tables using Joins.
- Applying aggregate functions and subqueries.
- Solving practical retail business problems.
